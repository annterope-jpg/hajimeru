# セラピスト伴走仕様 v0.5

> Phase 13：嫌悪とは別に開始前の判断・手順・準備の負担を任意確認し、本人が選んだ場合だけ判断削減を最大1件提示する。支援者は分類や正解を決めず、未回答・保留・終了を尊重する。詳細は`DECISION_FRICTION.md`を参照する。

確認日：2026-09-11
対象：本人端末上で行うUX試作評価  
状態：Phase 13まで実装済み。本人選択の感情別・状態別・判断削減支援を含む

## 1. 目的と境界

本人とセラピスト等の支援者が同じ端末画面を見ながら、着手に関する短い共同フォーミュレーションと1回の行動実験を作る。これは成人ADHDの診断、治療選択、心理療法、服薬判断、危機評価、治療遵守の確認を行う機能ではない。

初版は専門職アカウント、医療者ダッシュボード、遠隔監視、診療録連携を持たない。支援者向け説明も本人に見える。本人が端末を操作し、課題、回答、仮説、実験、共有範囲、終了を選ぶ。

## 2. 三者の責務

| 主体 | 行うこと | 行わないこと |
|---|---|---|
| 本人 | 共同利用への同意、今日扱う課題、回答、試す案、見せる範囲、終了・休息を選ぶ | 使用頻度や達成を証明する |
| セラピスト等 | 許可を取り、一度に1問だけ補助し、本人の語で仮説を照合する | 回答の上書き、使用の強制、診断・治療判断の委譲、欠測の否定的解釈 |
| アプリ | 回答済み情報を整理し、最大2つの課題側仮説、別枠の状態、30秒行動を提示する | 原因同定、効果判定、常時監視、自動共有 |

## 3. 現行試作で利用できる画面

| 目的 | 画面 | 伴走時の使い方 |
|---|---|---|
| 位置づけ確認 | 初回説明、しくみ、ヘルプ、共同利用ガイド | 原因を決めない小さな実験と本人の選択権を確認 |
| 今日の焦点 | ホーム | 本人の言葉で1課題だけ入力。機微情報を無理に書かない |
| 短い確認 | 開始の準備、詳細調整 | 本人が回答。一度に全項目を掘り下げない |
| 仮説照合 | 開始プラン | 本人が「近い・違う・まだ分からない」を任意選択 |
| 大きな課題 | ロードマップ | 正しい計画でなく、今・次・あとでの仮の地図を共同確認 |
| 行動実験 | タイマー、ふりかえり、「困った」後の調整 | 開始時点を成功とし、終了・継続・困ったを本人が選ぶ。困った後も縮小・判断削減・時間変更・休息・終了を本人が選ぶ |
| 記録を見る | 記録 | 回数や未実施を採点せず、本人が見せたい手がかりだけを見る |

現行版には本人が開始する「一緒に見るモード」がある。今日の焦点と終了目安を選び、全画面のバナーから終了できる。伴走状態は端末にも保存せず、再起動およびふりかえり終了後は単独利用へ戻る。

## 4. 共同利用セッションの状態契約

Phase 9の実装は、次の順序と境界を維持する。

1. `not_started`：単独利用が既定。支援者には何も送らない
2. `consent_check`：誰と、何を、どこまで一緒に見るかを本人が選ぶ
3. `focus_selected`：開始／ロードマップ／困った後／ふりかえりから1つ選ぶ
4. `formulation`：回答済み情報だけで仮説を提示し、本人が照合する
5. `experiment_agreed`：一歩、時間、止め方を本人が選ぶ
6. `ended`：伴走表示を解除。自動共有・バックグラウンド監視を残さない

通常の画面移動では伴走表示を維持し、本人の終了操作、アプリ再起動、ふりかえり終了で解除する。無操作時間による自動解除は入力消失を避けるため未実装であり、本人の一般設定として恒久的にONにしない。

## 5. データと権限

- 同じ画面を見ることは、AI、通知、同期、書き出し、診療録転記への同意を兼ねない
- 現行版は支援者へデータを自動送信せず、支援者の氏名・資格・連絡先も保存しない
- タスク本文、価値アンカー、不安・恥等の自由記述、将来のEFT記述は既定の共有対象にしない
- 本人が画面を見せる場合も、見せない・途中で閉じる選択を維持する
- 診療録へ必要事項を記載する場合、セラピストが所属機関の規程と本人への説明に従い、内容を自ら確認する。アプリ出力を自動転載しない
- Phase 18の共有要約が実装されるまで、アプリ内に「セラピスト共有済み」という状態を作らない

## 6. 安全とエスカレーション

アプリの安全ゲートは、通常AIへ送らない入力を保守的に振り分けるもので、臨床的リスク評価ではない。共同利用中に危機、虐待、重い身体状態、服薬上の問題、その他の安全上の懸念が明らかになった場合は、アプリを閉じ、資格範囲、所属機関の手順、地域の緊急対応を優先する。

アプリ内表示だけを根拠に「安全」と判断しない。通常提案を止めた分類結果を診断として扱わず、入力本文を公開Issueや通常ログへ貼り付けない。詳しくは`SAFETY_BOUNDARIES.md`に従う。

## 7. 逸脱防止要件

次を仕様上の回帰として扱う。

- セラピストだけに見える評価、未開始一覧、開始率、遵守スコアを作らない
- 本人の回答を支援者が上書きしない
- 「近い」以外を抵抗、否認、病識不足として扱わない
- 通知、AI、同期、共有を共同利用の条件にしない
- 不安を煽る、悪い未来を想像させる、厳密な締切を一律に課すことで動かそうとしない
- 低覚醒、freeze、回避、努力コストを診断的に決めつけない
- アプリ利用を診療上の利益・不利益や宿題評価へ直結させない

## 8. アクセシビリティと合理的配慮

本人の読字、視覚、聴覚、運動、言語化、デジタル操作の希望を開始前に確認する。支援者が読み上げる場合も回答を誘導しない。Dynamic Type、アプリ内大文字、スクリーンリーダー、Reduce Motionを使えるが、実機で本人と確認する。説明は一度に1つ、沈黙を待ち、言葉にしにくい場合はスキップを認める。

## 9. 試作評価の受入基準

- 別のセラピストが`THERAPIST_GUIDE.md`だけで5〜10分の模擬共同利用を進められる
- 導入時に目的・限界・中止・非共有を説明できる
- 最大2仮説を正解として教えず、本人の返答を得られる
- 提案が違う場合に回答見直し・動作縮小・見送り・休息を示せる
- 危機や服薬相談が出たらアプリを止め、所属機関の手順へ移れる
- 記録の多さ、未開始、欠測を治療遵守として採点しない

## 10. 既知の限界と公開条件

Phase 12の状態語と現地時刻は本人との照合材料であり、睡眠・概日・疾患・薬剤作用の判定材料ではない。セラピストは休息、時間変更、小さい一歩、相談の選択を本人と確認し、状態が強い・持続する・急に変化した場合は所属機関の手順を優先する。アプリは予約、紹介、遠隔監視、服薬助言を行わない。

Phase 11では、嫌悪に重なる分からなさ、評価への怖さ、恥・自責、圧力、退屈、freezeを本人選択で分けた。支援者は診断・原因推定に使わず、本人が希望した場合だけ開始前の準備を置く。緊急性や恥を動機づけに使わず、追加質問は最大2問とする。具体的な支援とデータ境界は`docs/EMOTIONAL_SUPPORT.md`に従う。

- 本仕様とマニュアルは専門家・当事者による正式レビュー前のv0.1である
- 過去の記録から「困った」後の調整を再開する導線と、Phase 18の本人主導共有要約は未実装
- セラピスト資格確認、組織契約、遠隔利用、診療録連携は対象外
- 医療機関での試用前に、責任者、同意、苦情・有害事象、個人情報、記録方針を各機関で確認する
- 一般公開や治療効果の表示前に、医療目的性、法務、安全、アクセシビリティの専門家確認が必要である
