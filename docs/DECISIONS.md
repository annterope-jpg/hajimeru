## 2026-09-10 — AI間の共通知識をGitHub上に置く
**決定:**  
ChatGPT・Chromeサイドバー・Codex・Hermesの実装文脈は、GitHub上の `AGENTS.md` / `PROJECT_CONTEXT.md` / `HANDOFF.md` / `DECISIONS.md` を共通基盤として受け渡す。

**理由:**  
各チャットやエージェントの会話履歴は自動共有されず、会話だけを正本にすると文脈が失われやすいため。

**代替案:**  
- 会話ごとに手作業で長い説明を再入力する。
- Obsidianだけを正本にする。
- GitHubだけですべての長期知識を管理する。

**見送った理由:**  
プロジェクト固有の実装情報と、仕事・副業などの横断知識を同じ場所に集約すると、最新版と公開範囲が分かりにくくなる。

**再検討条件:**  
AI間で安全かつ明示的な共有メモリ機能が提供され、GitHub側の引き継ぎが不要になった場合。
