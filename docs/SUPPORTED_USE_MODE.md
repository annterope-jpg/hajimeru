# 本人端末上の伴走モード仕様

版：0.2
確認日：2026-09-10
対象：Phase 10 UX確認用試作

## 目的

本人が近くにいる支援者と同じ端末画面を見ながら、5〜10分の共同フォーミュレーションを行えるようにする。モードは専門職機能の解放ではなく、本人と支援者が「今は一緒に見ている」と確認し、今日の焦点と終了の目安を共有する一時的な表示である。

## 開始条件

本人が次の3点を画面上で選ぶまで開始しない。

1. 今日の焦点：新しい一歩／大きな課題／困った後／記録の振り返りから1つ
2. 終了の目安：内容の確認／次の一歩の選択／短い実験の後から1つ
3. 「今、一緒に画面を見ることを選ぶ」という本人の確認

相手の氏名、資格、連絡先は入力・保存しない。本人が見せたくない内容がある場合は開始せず戻れる。AI、通知、同期は自動的にONにしない。

## 有効中の表示

- 全画面上部に「一緒に見るモード」、今日の焦点、終了目安、終了ボタンを表示する
- バナーを押すと設定内容と、送信が起きていないことを再確認できる
- 開始準備では、質問が正解や診断を決めるものではなく、迷う質問を飛ばせると共通表示する
- 開始プランでは既存の「近い・違う・まだ分からない」と見直し・見送りを使用する
- 支援者だけに見える説明、回答、スコア、記録は作らない

## 終了と保持

本人は上部バナーまたは確認画面からいつでも終了できる。短い実験後にふりかえりを保存またはスキップした場合も終了する。伴走セッションはZustandのメモリ内だけに置き、AsyncStorage、SQLite、同期、エクスポート、ログへ含めない。アプリ再起動後は単独利用へ戻る。

「終了の目安」は自動ロックではなく、開始前に共有する目安である。本人はそれより前に終了でき、希望すればその場で延長できる。将来、自動終了を導入する場合も本人の操作を奪わず、入力途中のデータを失わせない。

## 焦点ごとの開始位置

| 焦点 | 開始位置 | 現行の限界 |
|---|---|---|
| 新しい一歩 | ホーム | 課題文は同じ画面を見る相手にも見える |
| 大きな課題 | ホーム | 課題入力と短い確認後にロードマップへ進む |
| 困った後 | 本人向け記録 | 現在のタイマー後に本人が「困った」を選ぶと、アプリ内の再着手ループへ進む |
| 記録の振り返り | 本人向け記録 | 本人が開いた記録だけを共同で見る |

## 安全・プライバシー境界

- 同じ画面を見ることは、外部データ共有への同意ではない
- スクリーンショット、診療録転記、第三者への提示はアプリ外の別行為であり、所属機関の規程と別の説明・同意が必要
- 安全上の懸念が出たらモードを終了し、専門職責務と所属機関の手順を優先する
- アプリの安全ゲートは臨床的リスク評価の代わりではない
- 「違う」「分からない」「終了」を抵抗、病識、治療遵守の評価に使わない

## アクセシビリティ

開始選択肢はradio role、本人確認はcheckbox role、状態バナーと終了ボタンには読み上げラベルを付ける。選択領域は44px以上とし、Dynamic Type、アプリ内大文字、Reduce Motionを既存設定から継承する。色だけで伴走状態や終了操作を伝えない。

## 受入基準

- 本人の明示操作なしに開始しない
- 4つの焦点と3つの終了目安を選べる
- 全主要画面で伴走中と分かり、1操作で終了できる
- 再起動、ふりかえり完了、明示終了後は単独利用へ戻る
- 伴走状態や相手情報が保存・同期・書き出し・送信されない
- 質問意図と仮説修正が本人・支援者の両方に同じ内容で見える

## 既知の限界

- 近くにいる相手が実際に画面を撮影・記録することを技術的に防げない
- 「終了の目安」到達時の自動確認は未実装で、上部バナーから本人が終了する
- 過去の記録から「困った後」の再フォーミュレーションを開き直す導線はない
- 当事者・複数セラピストとの5〜10分実機評価はPhase 19まで未実施
