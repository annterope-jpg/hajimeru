# プライバシー方針（試作品）

最終更新: 2026年8月13日

> この文書は本人・関係者によるUX確認用試作品の説明です。正式公開前に、運営主体、連絡先、委託先、保存地域、保存期間を確定し、日本の個人情報保護法制に詳しい専門家の確認を受けてください。

## 基本方針

「はじめの地図」は、着手しにくい日常行動の条件を整理し、小さな行動実験を作るためのセルフマネジメント支援です。診断、治療、服薬指示は行いません。データは原則として端末内に保存し、同期とAI提案は利用者が個別に同意した場合だけ有効にします。セラピスト等と一緒に使う場合も、本人が見せることを選んだ画面やエクスポート以外を、自動的に支援者へ共有しません。

広告SDK、外部分析SDK、行動追跡SDKは使用しません。データを広告、信用評価、雇用判断、保険判断に利用しません。

## 取り扱うデータ

| 機能 | データ | 保存・送信先 | 必須性 |
|---|---|---|---|
| コア機能 | タスク文、7軸評価、開始プラン、タイマー、開始・終了記録、任意の振り返り | 端末内SQLite | コア機能に必要 |
| デイリー記録 | 睡眠感、気分、覚醒度 | 端末内SQLite | 任意 |
| 通知 | 開始キュー、通知時刻 | 端末の通知機能 | 任意・OS許可が必要 |
| AI提案 | その場のタスク文、タスク分類、選択済みボトルネック、言語、最大秒数 | Supabase Edge Function経由でOpenAI Responses API | 任意・個別同意が必要 |
| 同期 | タスク試行、デイリー記録、設定、削除マーカー | 利用者ごとのSupabase領域 | 任意・ログインと個別同意が必要 |
| アカウント | メールアドレス、認証識別子 | Supabase Auth | 同期を使う場合のみ |

AIへ睡眠、気分、覚醒度、過去の履歴、メールアドレス、アカウント識別子は送りません。AI入力は500文字までです。メールアドレス、電話番号、個人番号、カード番号らしい文字列を検出した場合は送信前に拒否しますが、機械的な検出ですべての個人情報を見つけられるとは限りません。

## 利用目的

- 入力したタスクから開始プランを表示し、開始と振り返りを記録するため
- 利用者自身に開始回数、開始率、役立った介入の傾向を表示するため
- 同意した端末間で記録を同期するため
- 同意した場合に限り、30秒以内の最初の行動を3案生成するため
- セキュリティ、不正利用防止、障害対応を行うため

目的を変更する場合は、変更内容を説明し、必要に応じて改めて同意を取得します。

## AI処理

Edge FunctionはOpenAI Responses APIへ `store: false` で要求し、OpenAI側の会話状態として保存する機能を使用しません。Edge Functionのアプリケーションログにはタスク本文もOpenAIのエラー本文も記録しません。

`store: false` は「いかなる保持もない」という意味ではありません。OpenAIの公式データ管理資料では、標準設定のAPI利用について、不正利用監視ログに顧客コンテンツが含まれ、原則最大30日保持される場合があると説明されています。短期テスト開始前に、利用するOpenAI組織・プロジェクトのデータ保持設定を確認してください。[OpenAI APIのデータ管理](https://developers.openai.com/api/docs/guides/your-data)

## 同期、保護、保存期間

- 同期データはSupabase Authの利用者IDで分離し、全テーブルでRow Level Securityを有効にします。匿名ロールには表の権限を付与しません。[Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security)
- 通信はHTTPSを使用します。データベースへの直接接続を運用する場合は、SupabaseのSSL強制を有効にしてください。[Supabase SSL enforcement](https://supabase.com/docs/guides/platform/ssl-enforcement)
- 保存時暗号化はSupabaseの管理基盤を信頼境界とします。この試作品は列単位暗号化やエンドツーエンド暗号化ではありません。正式利用前に契約、保存地域、バックアップ、暗号化条件を運営者が確認します。
- オフライン端末による復活を防ぐため、同期レコードの削除マーカーを削除時から30日間保持します。その後、信頼された定期ジョブで消去します。
- OpenAIへ送ったタスク本文はアプリのサーバーログへ保存しません。OpenAI側の保持は前節の方針に従います。
- 試作評価用のエクスポートは利用者本人が明示的に実行した場合だけ端末から生成します。

## 利用者による選択と削除

利用者は設定から次を個別に行えます。

- AIへの送信同意を撤回する
- 通知を停止する
- 同期を停止する
- 端末内の全記録を削除する
- 同期領域の記録とアカウントを削除する
- JSONまたはCSVで自分のデータを出力する

同期を停止しただけでは、すでに同期したデータは削除されません。「同期データを削除」または「同期領域の記録とアカウントを削除」を別に実行します。アカウント削除は、認証済みEdge Functionが本人の同期4表と削除マーカーを先に即時削除し、その後にSupabase Authアカウントを削除します。別利用者のIDをクライアントから指定する方式は使いません。管理権限の鍵は端末へ配布しません。

サーバー側のアカウント削除は、端末内SQLiteやオフラインの別端末に残るコピーを遠隔消去できません。操作した端末では成功後にローカル記録と認証セッションも削除します。他の端末に保存した記録は、その端末で個別に削除する必要があります。アカウント削除後も、法令・セキュリティ上必要な最小限の記録がある場合は、その種類・目的・期間を正式公開時の方針に明記します。

## 第三者提供・委託

利用者の同意なく、広告その他の目的で第三者へ販売または提供しません。AIまたは同期を選んだ場合、サービス提供に必要な範囲でSupabaseおよびOpenAIが処理委託先になります。正式公開前に、各社の契約条件、データ処理条件、国外移転の有無を確認して表示します。
