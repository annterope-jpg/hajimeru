# PROJECT_CONTEXT.md — 長期文脈

## プロジェクト
「いま、はじめる」

## 目的
成人の日常的な着手困難に対するセルフマネジメント支援の試作アプリ。タスク完了ではなく、最初の行動を開始できた時点を成功として扱う。

## 位置づけ
- 診断・治療・服薬判断を行う医療サービスではない。
- 成人ADHDに限定せず、診断の有無を問わず18歳以上の着手困難を対象とする。
- 現在はUX確認用の試作版であり、正式一般提供前に当事者参加評価、アクセシビリティ、セキュリティ、法務・医療目的性の確認が必要。

## 重要な設計原則
- 意欲や人格を評価せず、開始コストのボトルネックを扱う。
- 最初の30秒以内の行動へ落とし込む。
- 完了・連続達成・順位づけを成功条件にしない。
- コア機能は通信・ログイン・AIなしでも利用可能にする。
- AI提案は任意機能とし、安全ゲートとローカルフォールバックを維持する。

## 変更してはいけないもの
- 診断・治療アプリであるかのような表現への変更。
- ストリーク、順位、未達成を責める設計の追加。
- APIキーやservice role keyのクライアント側への埋め込み。
- 既存の安全・プライバシー制約の弱体化。

## 技術構成
- Expo / React Native
- SQLiteローカル保存
- 任意のSupabase同期
- 任意のAI提案

## 安全・プライバシー
- 個人を特定できる情報や秘密情報をGitHubへ記録しない。
- 公開リポジトリ上のHANDOFFには実症例・業務上の内部情報を書かない。
