# 本人主導の共有要約とふりかえり

Phase 18 の仕様。共有は「支援者へ送る機能」ではなく、本人が見せたい内容をその都度選び、送る前に確認できる補助とする。

## 目的

- 本人が、過去の一歩を一緒に振り返りたいときだけ共有用メモを作れるようにする。
- 課題名、作業仮説、小さな実験、戻る目印、ふりかえりを別々に選べるようにする。
- 記録全体を一括で渡さず、共有しない選択を常に残す。

共有要約は診療録、診断書、治療計画、専門職向け評価票ではない。アプリの出力も、本人と確かめるための作業仮説のままである。

## 利用者向けの動作

1. 「試した条件のメモ」から、共有したい一歩を本人が選ぶ。
2. 共有画面は何も選ばれていない状態で開く。
3. 本人が次の項目から見せてもよいものだけを選ぶ。
   - 取り組んだ課題
   - 今回の作業仮説
   - 選んだ小さな実験
   - 戻るための目印
   - ふりかえり
4. 選択した内容を画面で確認する。
5. 本人が「この内容を共有する」を押した場合だけ、OSの共有画面へテキストを渡す。

「共有せず戻る」を選んでも元の記録は変わらない。

## データ最小化と禁止事項

共有用メモには以下を含めない。

- 0〜10のアセスメント点数やふりかえり点数
- 未選択の項目
- 診断名、原因の推定、重症度判定
- 本人に見えない専門職向け評価
- 受取人ID、連絡先、共有履歴
- AIが生成した追加解釈

作業仮説は、本人が回答した結果から既に計画に残っている仮説ラベルだけを、非診断的な日本語へ変換する。欠測や未回答から内容を補わない。

共有選択は一時的な画面状態とし、保存・同期しない。共有先の選択と実送信はOSの共有機能が担当し、このアプリは受取人を保存しない。

## セラピスト・支援者との利用

支援者は「全部見せてください」を既定にせず、本人が何を一緒に確認したいかを先に確認する。共有されなかった項目を抵抗、意欲不足、隠蔽と解釈しない。

共有メモは診療録上の事実認定ではなく、その時点で本人が見せることを選んだ相談材料である。必要な臨床確認は通常の面接・評価手順で行い、診断・服薬・安全判断をこの要約から自動化しない。

診療録への転記、組織内共有、保存期間などは各施設の規則・法令を優先する。本人端末上で一緒に見ることと、データを別システムへ保存することは別の同意として扱う。

## ふりかえりの扱い

共有用メモでは、開始後の数値をそのまま共有しない。「一区切りにした」「もう少し続けた」「困って一歩を調整した」など、本人が記録した質的な範囲だけを表示する。

これは効果判定ではない。前後点の差、達成率、開始率、連続利用日数を本人・支援者向けの成績表示へ戻さない。

## 既知の限界

- OSの共有画面を開いた後の送信先、送信内容の二次利用、受取側の保存はアプリから制御できない。
- 画面撮影や手作業での転記は防止できない。
- 共有項目名や文章量が心理的圧力なく理解できるかは、Phase 19の当事者・セラピスト共同パイロットで確認が必要。
- 本人が共有した内容だけでは臨床評価に必要な情報が不足する可能性があり、それを自動補完しない。
