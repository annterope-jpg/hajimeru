# 本人主導の社会的随伴性：最小仕様

版：0.1  
対象：Phase 16

## 目的と位置づけ

人の存在や短い宣言が開始条件として合うかを、本人がその都度選ぶ任意の行動実験である。body doublingや報告が成人ADHDに有効と断定せず、治療遵守、監視、完了確認には使わない。

次の4条件を同等に提示する。

- 一人で進める
- 静かに同席してもらう
- 始める前にひとこと伝える
- 始めた後にひとこと伝える

「一人」は失敗や拒否ではない。人が関わる条件を選んだ場合だけ、「少し安心できそう」「圧力になりそう」「まだ分からない」を尋ねる。圧力または不明なら、一人へ戻す・今回は選ばない操作を目立つ位置に残す。アセスメント得点や感情回答から適性を推測しない。

## 定型文と外部境界

定型文はコード内の固定文で、タスク本文、氏名、連絡先、完了約束を含めない。選択した文は画面上で選択可能にするだけで、アプリ内送信、共有シート、連絡先参照、クリップボード操作、既読確認、返信確認、相手からの評価を実装しない。誰に・いつものどの手段で伝えるか、また伝えないかは本人が決める。

## データ境界とライフサイクル

`SocialSupportSelection`は列挙値だけを持つ進行中実験のメモである。`AssessmentDraft`、`InterventionPlan`、`TaskAttempt`、`SupportedUseSession`、`PersistedShell`に含めない。SQLite、AsyncStorage、AI、通知、同期、JSON/CSV、分析、伴走要約、ログへは流れず、アプリ再起動で消える。

プランからタイマー、ふりかえりまでは保持する。新規課題、履歴復元、再試行、ふりかえりの保存・スキップ、全ローカル削除、本人の取消で消去する。同席の選択は「一緒に見るモード」を開始せず、画面共有への同意にもならない。

## セラピスト併用

本人の選択を先に尋ね、静かな同席では次を合意する。

1. 会話・助言・進捗確認をせず、それぞれのことをする
2. 画面を見せるか、伏せるかを本人が決める
3. 途中でやめる短い合図を先に決める
4. 終了後は「助けになった／圧力が増えた／分からない」を評価せず確認する

証拠、送信履歴、連絡先、完了報告を求めない。一人や見送りを抵抗、重症度、治療意欲として解釈しない。安全上の懸念が生じた場合はアプリの実験より専門職責務と所属機関の手順を優先する。

## 既知の限界

効果は保存・集計しないため、Phase 16だけでは個人内の有用性を傾向表示できない。社会的支援の利用可否は生活環境や関係性に左右される。対人安全、ハラスメント、依存、境界の問題をアプリが評価するものではない。
