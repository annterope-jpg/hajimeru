# はじめの地図：目的・役割・境界

更新日：2026-09-03  
状態：UX確認用試作の製品境界（Phase 0）

## 名前

**はじめの地図**  
始めにくさをほどく、小さな行動実験。

旧称「いま、はじめる」は開始への焦点をよく表していた一方、改定後のアプリは、ただ即時着手を促すだけではない。止まっている条件を短く整理し、大きな課題の現在地と仮の方向を作り、30秒の一歩、時間変更、休息を本人が選ぶ。新名称は、この「診断ではない仮の地図」と共同フォーミュレーションの性質を表す。

既存の公開リンク、ローカルデータ、ディープリンクとの互換性を守るため、`hajimeru`というリポジトリ名、package名、slug、URL scheme、データベース名は当面変更しない。

## 目的

18歳以上で日常の行動を始めにくい人が、診断の有無を問わず、次を行えるようにする。

- 「やる気がない」と一括せず、今の開始コストを上げる条件を短く整理する
- 回答済みの情報だけから、最大2つの課題側の仮説と、必要な状態調整を選ぶ
- 最初の30秒の行動または大きな課題の仮のロードマップを作る
- 完了でなく、試しに開始したことを行動実験として扱う
- 合わなければ、本人の能力でなく条件・仮説・動作サイズを調整する
- 強い低覚醒や体調に合わせ、時間変更や休息も選べる

## 利用経路

### 本人単独モード

本人が自分の端末で、課題、回答、介入、記録、共有の有無を決める。AI、通知、ログイン、同期を使わなくてもコア機能を利用できる。

### セラピスト伴走モード

本人の同意を得て、本人とセラピスト等の支援者が同じ画面を見ながら、短い共同フォーミュレーションと行動実験を作る。初版では専門職専用ダッシュボードや自動共有を作らない。本人が操作し、本人が回答を修正し、本人が共有範囲を決める。

## 役割分担

| 主体 | 担うこと | 担わないこと |
|---|---|---|
| 本人 | 目標、課題、仮説、試す介入、共有、終了・休息を選ぶ | 利用頻度や達成をセラピストへ証明すること |
| セラピスト等 | 許可を得て質問を補助し、本人の語で仮説を確かめ、ずれを修正する | 監視、採点、使用の強制、欠測を意欲不足と解釈すること |
| アプリ | 情報を整理し、理由を説明し、小さな行動実験を提案・記録する | 診断、治療選択、効果判定、服薬判断、自動的な危機介入 |

セラピスト等が同席していても、アプリの出力は臨床判断ではなく、本人と確認する仮説である。面接中に安全上の懸念が明らかになった場合は、アプリではなく、専門職としての責務と所属機関の手順を優先する。

## 成功として扱うもの

- 最初の行動を開始した
- 今の条件に提案が合わないと分かった
- 動作を一段小さくできた
- 判断点や不確実性を一つ減らした
- 今は時間を変える、または休むと本人が選んだ
- 次に戻る目印を残した

タスク完了、開始率、連続利用、計画どおりの実施、セラピストへの報告は、本人画面の成功条件にしない。

## 行わないこと

- ADHDその他の診断・重症度判定
- 治療、心理療法、医療者による支援の代替
- 服薬の開始、中止、量、服用時刻の助言
- やらなかった場合の悪い未来を想像させること
- 未開始や不使用を責める通知、赤色、ストリーク
- セラピストへの自動共有、隠れた監視、治療遵守の採点
- アプリだけでの危機評価や会話型危機介入
- 本人の同意がないAI送信、同期、第三者提供

## 安全導線

危機、服薬変更、診断要求、個人情報を含む可能性が高い入力には通常のAI提案を返さない。必要な相談先を案内するが、アプリがリスクの程度を診断したり、専門職の臨床判断を置き換えたりしない。セラピストとの利用中は、所属機関の安全手順を優先する。

## Phase 0で決めた範囲と今後の変更管理

- 初版のセラピスト利用は、本人端末上の共同利用とする
- 専門職専用画面、遠隔モニタリング、診療録連携はPhase 20までの検討対象であり、現時点では実装しない
- 医療目的性、共有機能、危機対応の境界は、正式公開前に臨床・法務・プライバシーの専門家確認を受ける
- 名称、目的、対象、成功条件、禁止事項を変える場合は、本書、利用者向け説明、安全文書、テストを同じ変更単位で更新する
